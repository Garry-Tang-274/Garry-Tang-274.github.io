    <h2>How it works · 怎么用</h2>
    <p>AI suggestions use the same settings as the manual controls. You can adjust or undo them, compare the result with the original, and export a new file. The original photograph stays unchanged.</p>
    <p class="zh-secondary">AI 建议的参数和手动操作使用同一套控件，可以继续调整、撤销，或与原图对比。编辑完成后导出新文件，原始照片保留。</p>
  </section>

  <section class="cv-section">
    <h2>Features · 功能</h2>
    <ul>
      <li>Non-destructive Basic adjustments, HSL, RGB/channel curves, colour grading, masks, brush masks, and watermark layers.</li>
      <li>Before/after, undo/redo, histogram, zoom, full-resolution JPG/PNG export, and crash-recovery sessions.</li>
      <li>Optional AI connections: JarvisArt Local GGUF, Gemini, OpenAI, Qwen / DashScope, DeepSeek text adjustments, and custom OpenAI-compatible APIs.</li>
      <li>Local manual editing works without an AI account or API key.</li>
    </ul>
    <p class="zh-secondary">支持基础调色、HSL、曲线、蒙版、水印、历史记录和全分辨率导出。AI 可连接本地或云端模型；手动编辑不需要 AI 账号或 API 密钥。</p>
